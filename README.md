# IASAPPS Portfolio

IASAPPS is the portfolio of Isaiah Aris, showcasing selected web and iOS projects and providing a direct way to discuss a new website or application.

## Explore the portfolio

- **Selected Work:** Browse project summaries and dedicated case-study pages.
- **About:** Learn about Isaiah's background and approach to building digital products.
- **Resume:** View or download the portfolio resume.
- **Contact:** Find ways to get in touch about a project or collaboration.
- **Get an Estimate:** Describe a project through a six-step questionnaire and see a preliminary development range before sending a separate project inquiry.

The portfolio is built with Next.js, React, and TypeScript and published as a static website. Estimates are preliminary; final project scope, pricing, hosting, and ongoing services are discussed after review.
